# Linux: Права доступа

## Таблица прав
| Цифра | Права | Значение |
|-------|-------|----------|
| 7 | rwx | полный доступ |
| 6 | rw- | чтение и запись |
| 5 | r-x | чтение и выполнение |
| 4 | r-- | только чтение |

## Часто используемые права
- `644` (rw-r--r--) — обычные файлы
- `755` (rwxr-xr-x) — папки и скрипты
- `640` (rw-r-----) — конфиги с паролями
- `700` (rwx------) — приватные папки

## Команды
```bash
chmod 755 script.sh
chmod -R 644 files/ - курсивное изменение папки и файлов внутри
chown user:group file.txt - назначается владелец и группа владелец, не является прямым назначением прав для файла/папки.
chmod +x script.sh    # добавить исполнение, возмоэность запускать
find /var/www/myproject -type d -exec chmod 755 {} + - find /var/www/myproject -type d (к указанной директории и папкам внутри (d)) применить права 755
find /var/www/myproject -type f -exec chmod 644 {} + - тоже самое как в папках, тольоко применяется к файлам (-type f)
