# Linux Сетевые команды

## Основные команды
| Команда | Назначение |
|---------|------------|
| `ip a` | показать IP-адреса |
| `ip route` | показать маршруты |
| `ping -c 4 host` | проверить доступность |
| `ss -tulpn` | показать открытые порты |
| `curl -I url` | получить заголовки HTTP |
| `wget url` | скачать файл |
| `nc -zv host port` | проверить открыт ли порт |

## Полезные опции
- `ss -t` — только TCP
- `ss -u` — только UDP
- `ss -l` — только слушающие
- `ss -p` — показать процесс
- `ss -n` — не разрешать имена
