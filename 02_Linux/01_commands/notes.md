# Linux Day 1: Файловая система

## Полезные команды
- `ls -la` — подробный список всех файлов
- `ln -s target link` — создать символьную ссылку
- `ln target link` — создать жёсткую ссылку

## Разница ссылок
| Тип | Хранит | При удалении оригинала |
|-----|--------|------------------------|
| Символическая | путь | ссылка битая |
| Жёсткая | тот же inode | файл остаётся |

## Мой опыт
pwd, ls -la - where, who
mkdir -p /test{1,2,3,4} mkdir -p /test/1/2/3/4 - несколько папок в одной директории/структура папок 
touch, echo "test" > test_file - создание файлов/файлов с текстом
mv test/name1.txt test/name2.txt - переименовать, переместить

ln -s test/test.txt link.txt - ссылка символическая (при удалении становится битой), работает как ярлык в windows (может быть ссылкой на папку, даже на другом носителе)
ln test/test.txt hard_link.txt - жесткая ссылка (при удалении файла, данные остаются, ссылка действует только в одном разделе HDD)
ls -li - inode файла (у жестких ссылок, одинаковые)

grep - выполняет поиск по файлу. Флагами регулируются особенности поиска.
grep 'test' файл - поиск строк с наличием 'test'
-i - убирает регистр
-c - количество
-n - с номерами строк
-v - 'кроме' 'test'
-E - добавляет другие свойства флагам и значениям, позволяет например искать строки с несколькими значениями
grep -E 'test|test1' file | wc -l покажет количество строк с такими значениями.

grep 'test' файл | head -3  - первые 3 строки
grep 'test' file | wc -l  - количество, как и -c

найти строку с ..., но без ...  -  grep 'test' file | grep -v 'test1' - комбинирование
